# Execution logs

This directory contains all 48 original USEARCH logs used to construct direct
read-to-HiFi-pseudo-reference OTU tables: one minimum-size-one dereplication log
and one mapping/OTU-table log for each of 24 ONT subsamples. The dereplicated
FASTA files and per-read mappings are excluded; compact recall tables and the
analysis script are retained one directory up.
